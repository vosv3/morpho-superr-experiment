# Morpho · Superr style experiment

A design experiment, 11 Oct 2026: the Morpho front door (www.morphocompanion.com)
restyled to a warm notebook reference — cream paper, marker orange, soft display
type, outlined pill buttons, tilted prints and hand-placed stickers.

- Front page only. Copy is the live page's, word for word.
- The forms collect nothing: no input has a name, nothing is sent.
- `noindex, nofollow` on the page.
- Static HTML, no build step. Fonts: Fraunces and Geist from Google Fonts.

Not the live site. The canonical copy lives in James's Morpho workspace under
`launch/landing-page-superr-experiment/`.
